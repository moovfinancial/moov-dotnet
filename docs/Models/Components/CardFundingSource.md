# CardFundingSource

The funding source of the card. One of CREDIT, DEBIT, PREPAID, or UNKNOWN.

## Example Usage

```csharp
using Moov.Sdk.Models.Components;

var value = CardFundingSource.Credit;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `Credit`  | CREDIT    |
| `Debit`   | DEBIT     |
| `Prepaid` | PREPAID   |
| `Unknown` | UNKNOWN   |
