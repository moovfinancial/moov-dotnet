# IssuingControlsRestrictionMode

Whether the listed items are the only ones allowed (`allow`) or the ones to block (`block`).

## Example Usage

```csharp
using Moov.Sdk.Models.Components;

var value = IssuingControlsRestrictionMode.Allow;
```


## Values

| Name    | Value   |
| ------- | ------- |
| `Allow` | allow   |
| `Block` | block   |
