# ResolutionLink

A temporary, secure link sent to a merchant to resolve account requirements such as KYC verification or document uploads.


## Fields

| Field                                                                                 | Type                                                                                  | Required                                                                              | Description                                                                           |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `Code`                                                                                | *string*                                                                              | :heavy_check_mark:                                                                    | A unique nanoid identifier for the resolution link.                                   |
| `AccountID`                                                                           | *string*                                                                              | :heavy_check_mark:                                                                    | The ID of the merchant account this resolution link is associated with.               |
| `PartnerAccountID`                                                                    | *string*                                                                              | :heavy_check_mark:                                                                    | The ID of the partner account this resolution link is associated with.                |
| `Recipient`                                                                           | *string*                                                                              | :heavy_check_mark:                                                                    | The recipient contact information for the resolution link.                            |
| `Url`                                                                                 | *string*                                                                              | :heavy_check_mark:                                                                    | The URL of the resolution link.                                                       |
| `CreatedOn`                                                                           | [DateTime](https://learn.microsoft.com/en-us/dotnet/api/system.datetime?view=net-5.0) | :heavy_check_mark:                                                                    | The date and time the resolution link was created.                                    |
| `UpdatedOn`                                                                           | [DateTime](https://learn.microsoft.com/en-us/dotnet/api/system.datetime?view=net-5.0) | :heavy_check_mark:                                                                    | The date and time the resolution link was last updated.                               |
| `DisabledOn`                                                                          | [DateTime](https://learn.microsoft.com/en-us/dotnet/api/system.datetime?view=net-5.0) | :heavy_minus_sign:                                                                    | The date and time the resolution link was disabled, if applicable.                    |
| `ExpiresOn`                                                                           | [DateTime](https://learn.microsoft.com/en-us/dotnet/api/system.datetime?view=net-5.0) | :heavy_check_mark:                                                                    | The date and time the resolution link expires.                                        |
